Credit Card Default - Exploratory Data Analysis

Interactive EDA Tool - Analyze credit card default dataset from Kaggle

Upload train.csv and test.csv files to perform comprehensive exploratory data analysis including statistics, visualizations, and correlation analysis.

GitHub Pages Deployment Instructions:
  1. Create a public GitHub repository
  2. Commit index.html and app.js to the repository
  3. Go to Settings → Pages in your repository
  4. Select Source: Deploy from branch
  5. Select Branch: main, Folder: / (root)
  6. Save and wait for deployment (2-3 minutes)
  7. Access your app at: https://username.github.io/repo-name/
